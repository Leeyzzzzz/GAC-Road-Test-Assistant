四大架构创新

创新 1

混合注意力 CSA + HCA

CSA 将 KV Cache 沿序列维度压缩后做稀疏注意力，HCA 更激进压缩但保持 dense attention。两者分工，是百万 token 高效推理的核心突破。

创新 2

mHC 超连接

升级传统残差连接，通过流形约束控制信息流，让 1.6T 参数的超深网络也能稳定训练。

创新 3

Muon 优化器

首次在 LLM 训练中使用 Muon，通过梯度正交化实现比 AdamW 更快的收敛和更好的稳定性。

创新 4

FP4 量化感知训练

MoE 专家权重以 FP4 精度训练和存储，大幅降低显存和计算量，同时保持模型质量。

继承自 V3 的设计

DeepSeekMoE

细粒度专家分割 + 共享专家隔离，每个 token 仅激活少量专家。

Multi-Token Prediction

同时预测多个未来 token，提高训练效率，推理时可配合投机解码加速。

训练基础设施

融合 MoE Kernel

通信、计算、内存访问完全重叠的单一融合 kernel。

TileLang DSL

GPU Kernel 开发的领域特定语言，兼顾效率和开发效率。

确定性 Kernel

保证任意 batch 大小下训练和推理的 bitwise 一致性。

Autograd 扩展

Tensor 级检查点实现细粒度重计算控制，支持两阶段上下文并行。

推理基础设施

异构 KV Cache

热数据留 GPU HBM，冷数据迁 CPU 内存/磁盘，按访问频率动态调度。

磁盘持久化 KV Cache

将 KV Cache 写到磁盘，实现高效的共享前缀复用，避免重复计算。

OPD 亮点

创新的 On-Policy 蒸馏让学生模型在自身策略生成的数据上学习，配合全词表 Teacher 调度，实现在线知识迁移。

四大核心贡献

效率革命

1M token 推理仅需 V3.2 的 10%~27% FLOPs 和 7%~10% KV Cache，百万上下文日常使用成为可能。

训练创新

mHC + Muon + FP4 QAT 协同，实现 1.6T 参数模型在 32T+ tokens 上的稳定训练。

系统工程

TileLang → 融合 Kernel → 确定性计算 → 异构 Cache，全栈优化覆盖每个环节。

后训练体系

Specialist → OPD → RL @ 1M → Sandbox 完整流水线，解锁真实任务能力。
