2. 四大架构创新

创新 1

混合注意力：CSA + HCA

CSA (Compressed Sparse Attention)：将 KV Cache 沿序列维度进行压缩，然后执行 DeepSeek Sparse Attention (DSA)，利用稀疏性降低计算量。

HCA (Heavily Compressed Attention)：对 KV Cache 采用更激进的压缩策略（压缩率远高于 CSA），但保持全连接注意力（dense attention），避免稀疏计算的开销。

混合策略：两个注意力头各司其职——CSA 处理需要精细稀疏注意力的层，HCA 处理可以大幅压缩的层。这是实现百万 token 高效推理的核心突破。

创新 2

Manifold-Constrained Hyper-Connections (mHC)

对传统残差连接 (Residual Connections) 的升级。通过流形约束控制信息流动路径，让梯度在超深层网络中更稳定地传播。

mHC 使得模型在 1.6T 参数的超大规模下仍能高效训练，不会出现传统残差网络在深度增加时的退化问题。

创新 3

Muon 优化器

首次将 Muon 优化器应用于 LLM 训练。相比传统的 AdamW，Muon 通过 Newton-Schulz 迭代实现梯度矩阵的正交化，带来更快的收敛速度和更好的训练稳定性。

实现了混合 ZeRO 策略来高效支持 Muon 在大规模分布式训练中的内存需求。

创新 4

FP4 量化感知训练 (QAT)

在 MoE 专家权重和 Indexer QK 路径上引入 FP4 精度训练。通过量化感知训练确保模型在低精度下仍保持高质量。

在推理阶段，专家权重以 FP4 存储，大幅降低了内存占用和计算量。

3. 继承架构 (来自 DeepSeek-V3)

DeepSeekMoE

细粒度专家分割 + 共享专家隔离的 Mixture-of-Experts 框架。每个 token 仅激活少量专家，保持大模型容量的同时控制推理成本。

Multi-Token Prediction (MTP)

训练时同时预测多个未来 token，提高训练效率和数据利用率。推理时可配合投机采样 (Speculative Decoding) 加速。

4. 训练基础设施

通信-计算融合 MoE Kernel

将 MoE 模块的通信、计算和内存访问合并到单一融合 kernel 中，实现三者完全重叠执行，消除 GPU 空闲等待。

TileLang DSL

领域特定语言用于开发 GPU Kernel，平衡开发效率与运行时性能。比手写 CUDA 更快迭代，比纯 PyTorch 更高效。

Batch-Invariant 确定性 Kernel

保证训练和推理在任意 batch 大小下结果 bitwise 一致。消除因 batch 大小变化导致的精度漂移问题。

Autograd 扩展

Tensor-level 检查点 (checkpointing) 实现细粒度的重计算控制，平衡内存和计算。同时支持两阶段上下文并行 (Contextual Parallelism) 管理压缩注意力。

5. 推理基础设施

异构 KV Cache 结构

将 KV Cache 分为热数据 (GPU HBM) 和冷数据 (CPU 内存/磁盘)，根据访问频率动态调度。

磁盘 KV Cache 存储

支持将 KV Cache 持久化到磁盘，实现高效的共享前缀复用 (shared-prefix reuse)，大幅减少重复计算。

Specialist Training

针对不同能力维度（数学、编程、写作、搜索等）训练专门的专家模型，每个专家在特定领域达到最优性能。

On-Policy Distillation (OPD)

创新的蒸馏策略：让学生模型在自身策略生成的数据上学习，而非静态数据集。配合全词表高效 Teacher 调度，实现在线知识迁移。

RL 扩展到百万 Token

强化学习框架能处理 1M token 的上下文，配合可抢占和容错的 Rollout 服务，支持超长序列的 RL 训练。

Agentic AI 沙箱基础设施

为 Code Agent 等场景构建安全隔离的执行环境，支持模型在真实环境中交互学习。

8. 核心贡献总结

效率革命

通过 CSA+HCA 混合注意力，百万 token 推理仅需 V3.2 的 10%~27% FLOPs 和 7%~10% KV Cache，使百万上下文的日常使用成为可能。

训练创新

mHC 超连接 + Muon 优化器 + FP4 QAT，三者协同实现了 1.6T 参数 MoE 模型在 32T+ tokens 上的稳定训练。

系统工程

从 TileLang kernel 开发到异构 KV Cache 管理，从融合 MoE 通信到磁盘缓存，全栈优化覆盖训练和推理的每个环节。

后训练体系

Specialist Training → OPD → RL @ 1M → Agentic Sandbox 形成完整后训练流水线，解锁模型在真实任务中的能力。
