📋 优化方案总结

  • 设计语言统一 — 所有页面使用 #1E293B 主色 + 白色卡片 + 24rpx圆角，消除export页面的旧版蓝色渐变
  • 操作收敛 — 页面内操作按钮不超过2个，次要操作收入"⋯"菜单或滑动操作
  • 信息密度提升 — 卡片增加严重度色条、状态标识、进度信息，一眼可读
  • 表单反馈增强 — 实时校验 + 自动保存指示，提升填写信心
  • 卡片组件化 — 统一使用 t-tag/t-button/t-cell-group，消除自定义样式标签
  • 导出页面翻新 — 完全重写export页面的模板和样式，对齐设计系统
  • 归档页面差异化 — 减少与首页的同质化，增加筛选和批量操作
  • Touch Target — 所有交互元素 ≥44pt，关键操作有loading/disabled状态
  • 底部安全区域 — 固定元素使用 env(safe-area-inset-bottom)
优先级建议：

P0 · 高优先级 — 导出页面翻新（风格完全不同，影响品牌一致性）
P1 · 中优先级 — 首页卡片操作优化 + 搜索筛选（影响日常使用效率）
P2 · 中优先级 — 项目详情卡片紧凑化（影响信息可读性）
P3 · 低优先级 — 归档页面差异化（使用频率低）
P3 · 低优先级 — 试验详情记录卡片增强（已有部分实现）
