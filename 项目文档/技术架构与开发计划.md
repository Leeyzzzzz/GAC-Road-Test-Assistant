## 🎯 一、胶水编程核心理念

### 1.1 指导原则

| 原则 | 说明 |
|-----|------|
| 非必要不写代码 | 任何具有现有成熟实现的功能都不应从头重建 |
| 复制粘贴即工程 | 直接使用经过社区验证的代码 |
| 站在巨人的肩膀上 | 利用现有的框架，不重新发明轮子 |
| 零幻觉原则 | 仅使用经过验证的、成熟的代码 |
| 复杂性外包 | 将复杂性委托给社区 |

### 1.2 项目定位

```
本项目 = 成熟组件（实体） + 胶水代码（连接） + 少量业务逻辑
```

### 2.2 技术栈选型详解

#### 2.2.1 前端技术栈

| 技术 | 选型 | 选型理由 |
|-----|------|---------|
| **前端框架** | React | 你有 React 经验，学习成本低 |
| **UI 组件库** | Ant Design (AntD) | - 企业级 UI 组件库&lt;br&gt;- 组件丰富，开箱即用&lt;br&gt;- 符合中国人审美&lt;br&gt;- 文档完善，社区活跃 |
| **状态管理** | Zustand / Redux Toolkit | 轻量级状态管理 |
| **路由** | React Router v6 | 官方推荐路由方案 |
| **HTTP 客户端** | Axios | 成熟稳定，拦截器强大 |
| **构建工具** | Vite | 开发体验好，构建速度快 |

**为什么选 React + Ant Design？**
- ✅ 你有 React 经验，快速上手
- ✅ Ant Design 组件丰富，不用自己写 UI
- ✅ 大模型（GLM-5、豆包）对 React + AntD 支持好
- ✅ 符合"简洁美观"的界面需求

#### 2.2.2 后端技术栈

| 技术 | 选型 | 选型理由 |
|-----|------|---------|
| **Web 框架** | FastAPI | - Python 技术栈&lt;br&gt;- 性能好，异步支持&lt;br&gt;- 自动生成 API 文档&lt;br&gt;- 类型提示，IDE 友好 |
| **核心组件** | Kiwi TCMS | - 成熟的测试用例管理系统&lt;br&gt;- Python + Django 技术栈&lt;br&gt;- 完善的 API（JSON-RPC/XML-RPC）&lt;br&gt;- Docker 一键部署&lt;br&gt;- 2M+ Docker 下载，社区活跃 |
| **数据库** | PostgreSQL | - Kiwi TCMS 官方推荐&lt;br&gt;- 支持 JSON 字段，灵活存储扩展数据&lt;br&gt;- 性能好，稳定可靠 |
| **Kiwi API 客户端** | tcms-api | - 官方 Python 客户端&lt;br&gt;- 封装完善，使用简单 |
| **企业微信 SDK** | wechatpy / 官方 SDK | - 官方维护，稳定可靠&lt;br&gt;- 功能完善 |

**为什么选 Kiwi TCMS 而不是自研？**
- ✅ 测试用例管理核心功能已完善
- ✅ 不用从零写 CRUD、权限、导入导出等
- ✅ 专注于业务逻辑和界面定制
- ✅ 符合"胶水编程"理念

#### 2.2.3 部署与运维

| 技术 | 选型 | 选型理由 |
|-----|------|---------|
| **容器化** | Docker + Docker Compose | - 环境一致，部署简单&lt;br&gt;- 一条命令启动所有服务&lt;br&gt;- 升级回滚方便 |
| **反向代理** | Nginx Proxy Manager | - 可视化配置&lt;br&gt;- 一键申请 SSL 证书&lt;br&gt;- 不用手写 Nginx 配置 |
| **监控（可选）** | Portainer | - Docker 可视化管理&lt;br&gt;- 查看日志、重启容器&lt;br&gt;- 简单易用 |

### 2.3 业务层级映射方案

| 你的业务层级 | Kiwi TCMS 原生概念 | 说明 |
|------------|-------------------|------|
| **项目层** | Product（产品） | 映射为 Kiwi 的 Product |
| **工作表层** | TestPlan（测试计划） | 映射为 Kiwi 的 TestPlan |
| **一级分类** | Category（分类） | 映射为 Kiwi 的 Category |
| **二级分类/用例** | TestCase（测试用例） | 映射为 Kiwi 的 TestCase，用 Tag 区分二级分类 |

**数据存储策略：**
- Kiwi TCMS：存储核心测试用例数据
- PostgreSQL（胶水服务）：存储层级映射关系、审批记录、扩展属性等

## 🔧 五、部署方案

### 5.1 本地开发环境

```bash
# 1. 克隆项目
git clone &lt;repo-url&gt;
cd 路测助手

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env 文件

# 3. 启动所有服务
docker-compose up -d

# 前端: http://localhost:5173
# Kiwi TCMS: http://localhost:8080
# 胶水服务 API: http://localhost:8000
# API 文档: http://localhost:8000/docs
```
