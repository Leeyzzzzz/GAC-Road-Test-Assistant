Vibe coding流程

### **1 明确需求**

把系统要实现的功能拆成一个个需求点

### **2 使用 GPT/Grok 拆解需求**

让 AI 将需求细化为可复用模块、能力点和对应的子任务

### **3 搜索现成的开源实现**

利用 GPT 的联网能力（如 Grok）：

* 根据每个子需求搜索对应的 GitHub 仓库
* 检查是否存在可复用组件
* 对比质量、实现方式、许可证等

### **4 下载并整理仓库**

将选定的仓库拉取到本地，分类整理

### **5 按架构体系进行组织**

把这些仓库放置到项目结构中，例如：

```
/services  
/libs  
/third_party  
/glue  
```

并强调：**开源仓库作为第三方依赖，绝对不可修改。**

### **6 编写胶水层代码**

胶水代码的作用包括：

* 封装接口
* 统一输入输出
* 连接不同组件
* 实现最小业务逻辑

最终系统通过多个成熟模块组合而成


### **7 验收** 

验收标准：

* 功能符合需求规格
* 接口稳定、文档完善
* 性能满足要求
* 代码质量符合标准
* 符合架构设计
